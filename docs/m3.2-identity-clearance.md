## Trademarks and active-brand searches

The official search entry points for USPTO, WIPO Global Brand Database, EUIPO,
and IP India each returned HTTP 200:

- `https://tmsearch.uspto.gov/search/search-information`
- `https://branddb.wipo.int/branddb/en/`
- `https://euipo.europa.eu/eSearch/`
- `https://tmrsearch.ipindia.gov.in/tmrpublicsearch/`

Their interactive/session-based interfaces did not provide a reproducible exact
word-mark export during this unattended run. Indexed web searches found no
conclusive exact `VNStack` or `VNPyKit` software mark. They did find descriptive
academic use of `VNStack` and the established `vn.py` software brand. These
searches cannot establish registrability, ownership, territory/class coverage, or
freedom to operate. A qualified trademark search remains open.

## Gate result

No identity is approved. `VNStack` has unresolved exact GitHub, npm-scope, and
`.com` ownership conflicts. `VNPyKit` has unresolved `vn.py` confusion and does
not yet have controlled npm/GitHub identities. Per the M3.2 migration gate, active
package names, imports, CLI names, generated output, and documentation remain
`VisionPy`; ADR-0008 is intentionally absent.
