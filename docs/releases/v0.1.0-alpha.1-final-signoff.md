## Owner decisions

The owner keeps the VNPyKit brand and the existing Python, npm, executable,
repository, and directory names. The owner accepts the residual trademark and
brand-confusion risk for this first public alpha based on the preliminary
evidence below. This is a release risk decision, not a declaration of formal
legal clearance, worldwide availability, non-infringement, or zero confusion
risk.

The owner-designated search and evidence date for this release record is
2026-10-13. The EUIPO results below are supported by supplied screenshots; the
USPTO and India results are owner-reported:

- EUIPO eSearch plus screenshots: searches for `VNPYKIT`, `VNPY`, `VN.PY`, and
  `VEIGHNA` returned no records.
- EUIPO eSearch plus screenshot: `PYKIT` returned `BehappyKitchen`, an unrelated
  mark in Nice Classes 29, 30, 32, 35, and 43.
- USPTO: owner-reported searches for the supplied names and variants returned no
  record. This result was not independently reproduced in this sign-off.
- India: owner-reported searches for the supplied names and variants in Classes
  9 and 42 returned no record. This result was not independently reproduced in
  this sign-off.

The owner also accepts a VoiceOver/Safari manual-testing waiver for this alpha.
VoiceOver with Safari remains **NOT RUN** and is not represented as passing.
Users should treat macOS screen-reader behavior as an unverified alpha
limitation. Automated browser accessibility checks passed, and the earlier
Windows accessibility checks remain owner-reported rather than independently
certified.

## Security and registry state

Live GitHub API checks on 2026-10-13 independently confirmed:

- the repository is public;
- Private Vulnerability Reporting is enabled;
- secret scanning and push protection are enabled;
- Dependabot security updates are enabled with zero open vulnerability alerts;
- CodeQL default setup is configured and has completed Actions, Python, and
  JavaScript/TypeScript analyses for the release commit;
- GitHub Actions full-length SHA enforcement is enabled; and
- the protected `main` and exact `v0.1.0a1` tag rulesets remain active.

All tracked workflow action references are full immutable commit SHAs. GitHub
Actions still allows all external actions at repository level, and the release
environments have no required reviewers. Those are documented residual
hardening opportunities; the exact tag policies, ten-minute timers, disabled
administrator bypass, workflow ref guard, and least-privilege job permissions
remain active.

The owner confirms that the PyPI Pending Trusted Publisher is bound to exact
environment `public-alpha-pypi`. The owner also reports revalidated npm identity
`visionnumbers` and owner access to organization `vnpykit`. These registry
account facts are owner-confirmed because they are not exposed by public APIs.
