## npm Trusted Publisher setup after bootstrap

A Trusted Publisher cannot be configured until its package page exists. On each
of the five package pages, open **Settings > Trusted Publisher**, choose
**GitHub Actions**, and enter:

- Organization or user: `visionnumbers`
- Repository: `vnpykit`
- Workflow filename: `release.yml`
- Environment: leave blank until `public-alpha-npm` is actually configured
- Allowed actions: stage-only is preferred; enable direct `npm publish` only
  while the reviewed workflow uses direct publishing; do not enable dist-tag
  management unless required

Create these connections only immediately before a planned follow-up version:
npm expires a new Trusted Publisher that has not completed a successful publish
within two days. After OIDC succeeds, set publishing access to require 2FA and
disallow traditional tokens.

npm automatically produces provenance for Trusted Publishing only when both the
package and source repository are public. The current private repository cannot
produce npm provenance.
