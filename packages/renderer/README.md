# @vnpykit/renderer

The safe, Shadow DOM-scoped renderer for VNPyKit protocol major 1. It renders an
allowlisted component tree with native form controls, text-only content updates,
bounded property patches, delegated events, and instance-scoped teardown.

Most applications should use `@vnpykit/embed` or `@vnpykit/cli`. This lower-level
package is available for custom runtime integrations. Apache-2.0; public alpha.
