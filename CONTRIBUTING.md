# Contributing to VNPyKit

Read both architecture documents and `AGENTS.md` before changing a public contract. Keep changes scoped to one milestone or issue, add contract tests, and report all validation commands. Contributions must not introduce CodeLab dependencies or claims that Workers securely isolate hostile code.

The RFC source text retains the VisionPy historical development context. Current
Python code imports `vnpykit`, npm workspaces use `@vnpykit/*`, and the CLI command
is `vnpykit`.
